Each card links to the terminal at /box/new?theme=<id>. Themes 01, 02 and 06 are built; the others open the closest built theme and say so.

How a theme is made

  1. A theme is one record: a token bundle written in the dialect.
  2. Its fields are surface material, bezel material or none, cursor, motion rule and response source (mouse, eyes, tilt or nothing).
  3. Switching themes is one record change; the composer, the ledger and the actions registry do not move.
  4. Any agent can write a new theme as text, so a theme can arrive in a message and be tried the same minute.
  5. Example:
glass-window = { surface: glass over fog, airy · bezel: none · cursor: glow, white, etched · motion: drift, slow · responds: mouse | eyes }

Recommended first three to build

  • Blank Page, because it is the floor of simplicity on a light surface and proves the composer works with no chrome at all.
  • Void, because it is the same floor on a dark surface and gives the phosphor family its base.
  • Glass Window, because it is the one Justin loves and the base that You as the Camera and Tilt Window are built on.
