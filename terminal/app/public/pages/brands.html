Brand marks

Every company, product and tool named so far, as stored SVG. Each gathered mark ships in six configurations: official colour, mono (takes the text colour), fixed light, fixed dark, and two lockups of ours (wide and stacked) that put the name next to the icon in the house font. All files are transparent. Sources and terms per file are in the registry; rules in the logos-and-icons skill; the machine-readable list is brand/index.json.

Sizes

Every mark is checked at 16, 24, 48 and 128 px on both page themes. This row shows the mono configuration of the first mark at each size.

Configurations are generated by node scripts/brand-variants.mjs from the colour file; edit the source and re-run rather than editing variants by hand. Raster PNG export, tracing raster-only logos to vectors, and 3D versions are later, costed layers (see the skill).
