## Fix after the first live check (2026-09-29)

- On the live site the first self-edit prompt reached the Sonnet 5.5 retry, and OpenRouter's provider for it (Amazon Bedrock) refused the request: `tool_choice: type "tool" and "any" are not supported for this model`. Nothing was applied and the reply showed the raw error body.
- Fixed in `shared/src/agent/turn.ts`: when a provider refuses `tool_choice: "required"`, the same round is sent again with `"auto"` (the system prompt still requires tools). When the retry round itself fails, the reply shows the first try's rejection reasons and a one-line note instead of a provider dump. `readableError()` extracts the provider's message from OpenRouter error bodies. The router now ledgers the rounds that ran even when a turn fails, because the provider billed them.
