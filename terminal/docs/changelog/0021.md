# 0021 — Recoverable prompt runs and a useful local demo

2026-10-04. Source: Justin's private assistant conversation, requesting repair of freshterminal.ai and relevant lessons from Playset's prompt-box chip experiments. No public message permalink is available.

- A failed router health probe no longer disables prompts for the rest of the visit. Successful probes are cached briefly; failed probes can recover on the next attempt.
- Router streams release listeners and timers on every exit, handle CRLF events, and report one failure while preserving the server's final billing receipt.
- Stop works during device/session preparation and direct-key requests. Leaving a stage aborts its active prompt and prevents a late response from navigating to a new page.
- An empty composer offers an opt-in no-cost demo: create a page, change to Blank Page, or show today. Choosing a sample fills an editable draft; only Send executes it. The three exact sample prompts use local commands and skip paid tagging.
- Draft words survive refresh, stage changes and the first-run composer relocation. Recovering a failed prompt keeps newer typing and does not submit automatically.
- Running, complete, error and stopped feedback is visible beside the composer. Stop is a real touch/keyboard control, and a synchronous lock prevents overlapping prompt submissions.
- Inline semantic colors keep the exact textarea glyph widths, so moving the caret or selecting text stays aligned. Interactive, named chips remain below the writing surface. Starter suggestions stay keyboard/click reachable when the textarea loses focus.
- Existing local edits remain undoable. No account, access, credit, publishing or data migration settings changed.
