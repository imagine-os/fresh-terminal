# 0008 — free credits enforced by the router

Date: 2026-09-29. Model: Opus 5.5. Canon prompt 67. Decision 0021. Canon C-074.

## Shipped

- D1 migration `0002_credits.sql`: `anon_devices`, account grant columns, `spend_daily`.
- `router/src/credits.ts`: signed device ids, the meter on paid endpoints (grant, two soft prompts, then sign-in; account grant; daily anonymous cap; per-IP and per-network rate limits; 60 KB anonymous body cap; default models and no escalation signed out), `GET /credits`, `POST /credits/device`; `/health` reports `credits`. Workers Rate Limiting bindings `RL_IP` (30/min) and `RL_NET` (120/min). `router-deploy` creates `DEVICE_SIGNING_KEY` once.
- App: `routerFetch()` for every router call (device id, Clerk token, one re-issue on `device_required`), `useCredits()` for the tray, credits errors and soft prompts as system lines in the box (EN/ES), `ft:action` `auth.signIn` / `auth.signOut` / `sync.now` handled by the account provider. First-run notice and session export are Justin's session's (C-072).
- `sync-smoke` workflow: after each router deploy (and on demand), a throwaway Clerk development user checks `/me`, `/sync/*` and `/credits` live, an anonymous device makes one real call, then the rows and the user are deleted.
- `infra-verify` also checks Turnstile access (readable). Turnstile: `router-deploy` finds or creates the invisible widget and pushes its secret and site key; `POST /credits/device` then needs a passing token; the app runs the widget once (`app/src/lib/turnstile.ts`).
- Tests: signing and forgery, /24 and /48 grouping, grant → 2 soft prompts → 402, no second grant, per-IP and per-network issue limits, daily cap, body cap, rate limit, account grant, cost extraction from JSON and SSE, `/route` metering and the anonymous model rule, `routerFetch` against the real router, first sign-in uploading every local box.
