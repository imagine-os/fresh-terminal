# 0001 — first pass

Date: 2026-09-28. Model: Fable 5.1. Branch: `main`.

## Shipped

- Repo shape: `README.md` + `terminal/` (+ `.gitignore`, `.github/workflows`, root `package.json` proxy, `pnpm-workspace.yaml`).
- `shared/`: product name constant; layout dialect v0 (parser, printer, zod, 8 tests); chip tagger (9 tests); ledger with pure-TS sha256, hash chain, verify, integer money (10 tests); billing dialect (6 tests); theme records + dialect + three seeds (6 tests).
- `module/`: SpacetimeDB TypeScript module with tables `box, session, line, presence, route_rule, owner, entry, theme` and reducers `create_box, open_session, append_line, touch_presence, upsert_route_rule, set_on_chain, append_entry, upsert_theme`. Type-checks against `spacetimedb@2.10.1`. Not published.
- `router/`: Hono app; `GET /health`, `GET /rules`, `POST /route` streaming SSE from OpenRouter with `usage.include`; route table with tiers (JEV pending); one charge entry per call; Node entry (bundled to `router/dist/node.mjs`) and Worker entry (`wrangler.toml`); 13 tests.
- `app/`: five-region Shell from the dialect spec (container queries in rem, clamp type scale, no pixel media queries); composer that grows upward with Enter/Shift+Enter and Web Speech mic; live chips inline; suggestion strip filtered by what exists; transcript with streaming; boxes per anonymous visitor with `/box/:id`; top bar with shortcut tooltips and live "$x used"; dev mode (right sidebar) with live dialect editor, size readout, theme picker, PM viewer (kanban/list/timeline by dependency depth), ledger table + verify + export + on-chain opt-in, actions list, not-wired list; EN/ES for every string; keyboard shortcuts `N [ T D L`; doodle hints; three themes; local commands (`list my boxes`, `show today`, `open settings`, `make a page called "X"`) so it works without a key.
- Hosting: `pages.yml` (GitHub Pages via Actions, SPA fallback) and `ci.yml` (typecheck, test, build).
- `pnpm check:responsive`: Playwright at 360/390/768/1280/1920/2560/3840 for `/` and `/box/:id`; screenshots and `responsive-latest.md` in `docs/qa/`.
- Starters: 14 sample starting prompts as records (`docs/prompts/starters.json`, `shared/src/starters`, 4 tests); the suggestion strip reads them. `Reveal` wrapper paints replies in like a CRT beam (horizontal with scan line, radial, diagonal, typewriter). "Draw a shadcn dashboard" and "Draw a login screen" render demo compositions (labelled, not wired to the model); "Draw a kanban of the plan" renders the real plan. Local handlers for switch theme, set dialect, verify chain, speak, translate, charge-me-nothing (reply only).
- Pages: `pages/audit.html` and `pages/themes.html` ship with the app; every theme card has "Open full screen" → `/box/new?theme=<id>` (13 unbuilt themes fall back with a toast).
- Master canvas at `/canvas` (`C`): pan/zoom with pointer, wheel, pinch, keyboard; card records with 1 mm paper / 10 mm image thickness rendered as an edge; five seed cards; in-place page rendering without iframes; `pnpm -C terminal canvas:add`. Module gets a `card` table.
- Docs: this folder.
