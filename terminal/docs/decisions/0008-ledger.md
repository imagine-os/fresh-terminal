# 0008 — ledger at the core; the simplest chain

- Money is an integer count of micro-dollars (1/1,000,000 USD). Never floats. `formatMicro` prints; `dollarsToMicro` rounds once at the provider boundary. One "credit" in the billing dialect is one cent (10,000 micro).
- `entry` fields: id, box_id, owner_identity, kind (`charge|credit|settle`), what (`model.call`, `storage`, `action:<id>`), units, unit_kind (`token_in|token_out|byte|call`), cost_micro (our cost), price_micro (what the user pays), ref (provider id), created_at, prev_hash, hash, shared_prev_hash, shared_hash. Balance and "used" are computed from entries, never stored.
- Pass-through: the router asks OpenRouter for `usage: { include: true }`; `cost` becomes `cost_micro`; if absent, `router/prices.json` computes from tokens. `price_micro = cost_micro + margin` where the margin is basis points from the route rule (default 0). One entry per call with `unit_kind: 'call'`; token counts travel in the `done` event. Token-level entries are a later refinement.
- Where entries are written: the router emits the draft in the SSE `done` event; the app chains and stores it (fallback store). With SpacetimeDB the module reducer `append_entry` stores it; recomputing hashes inside the reducer is pass 2.
- The chain: `hash = sha256(prev_hash + canonical JSON of {id, box_id, owner_identity, kind, what, units, unit_kind, cost_micro, price_micro, ref, created_at})`. Per-owner chain always (first entry links to 64 zeros). Owners who opt in ("on chain", stored on the `owner` record) also link every entry into one shared sequence. `verifyLedger` checks all owner chains and the shared chain; `pnpm -C terminal verify:chain file.json` and the dev panel's "Verify chain" run it. Tampering with any field or removing an entry breaks every hash after it (tests cover both).
- Plainly: no tokens, no wallets, no mining, no consensus. It is an append-only, hash-linked, verifiable ledger that anyone holding the export can check.
- Billing dialect (`shared/src/billing`): `Model calls: pass-through plus 0%. Storage: 1 credit per MB per month. Actions: free. Settle: manual. On chain: opt-in.` Margins are integer basis points; amounts integer micro-dollars. Unknown words are reported.
- Not wired: Stripe settlement (placeholder button), publishing the shared chain beyond the browser.
