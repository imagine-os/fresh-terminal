# 0018 — skins and the refine loop

Date: 2026-09-29. Model: Opus 5.5. Prompt: 0013. Canon: C-030, C-031 (now built).

- **A skin is a record, like a theme.** `shared/src/ui/skin.ts`: `{id, name, target, path, tokens, background, image, veil, request, description, score, round}`. Targets: `shell`, `stage`, `sidebar`, `topbar`, `composer`. `tokens` are CSS custom properties scoped to that region. `background` is CSS gradients and colours only: `isSafeBackground()` allows `linear-`, `radial-`, `conic-` (and `repeating-`) gradients, `rgb/rgba/hsl/hsla/oklch/oklab/color-mix/var/calc`, and nothing else (no `url()`, no escapes, balanced brackets). `image` is an `idb:<key>` stored in this browser or an `https` URL, always with title, creator, licence, licence URL and source. `veil` (0–90 %) lays the plain background over the material so text stays readable; `ensureReadable()` forces text colours to at least 4.5:1 on the skin's background.
- **`skin.apply` and `skin.clear` are ops.** They go through the same engine as every other edit: atomic, validated again inside the engine, undoable (the inverse restores the previous skin or clears it), ledgered as `edit`. The chat model also gets `skin_apply` for CSS-only skins.
- **The flow.** "skin the sidebar brass" (or any prompt Jev routes to the new `skin` intent) does four things:
  1. **Draft at once**: `draftSkin()` picks the closest library material, or a colour tint, or a labelled stand-in, and applies it before any network call.
  2. **Jev picks the path** (`POST /skin/plan`): a Choice over `library`, `procedural_code`, `css_tokens`, `image_search` (Openverse) and `image_generate` (OpenRouter image model), told the budget.
  3. **refine()** (`shared/src/refine/loop.ts`): best of 3 per round. Round 1 makes 3 variants; each later round makes 3 upgrades of the current best (CSS: the model rewrites the winner; image search: Openverse "related" images of the winner; image generation: the winner image is sent back with an improve instruction; library: the next materials). Scoring (`POST /skin/score`): one vision call describes the image variants and proposes a palette (Gemini 2.5 Flash-Lite), then one Jev call scores every variant on five ordered rungs; the score is the probability-weighted rung.
  4. **Stop rules** from `router/rules.json` → `refine`: score ≥ 4.5, 2 rounds without a better best, 5 rounds, the 3¢ cap (checked before spending, from per-variant estimates), or the user pressing Stop. Each new best is applied as it arrives; any version can be picked from the thumbnails; Undo walks back through them.
- **Every call is ledgered**: `skin.plan` (Jev), `skin.code` (Haiku 4.5), `skin.search` (Openverse, $0), `skin.image` (image model), `skin.vision` (Flash-Lite), `skin.score` (Jev), plus `skin.route` when Jev routes a prompt to skins.
- **Image model**: `openai/gpt-5-image-mini`, the cheapest image-output model on OpenRouter by image-token price on 2026-09-29. `google/gemini-2.5-flash-image` is about $0.039 an image by its listed price, more than the whole 3¢ cap.
- **Storage**: generated images are re-encoded as JPEG and kept in this browser's IndexedDB; records hold only the key. Nothing is stored server-side yet (Canon C-053 proposes R2). Openverse images are linked, not copied, with their licence recorded on the skin and shown under the run.
- **UI**: the reply shows the run: status line (material, part, path, rounds, spend against the cap, best score), the draft, one row of three thumbnails per round with scores, the winner outlined, a check on the one applied, Stop while running, the stop reason, and licence lines for searched images.
- Rejected: letting the model write arbitrary CSS or HTML (not checkable); hot-linking images without their licence; running the loop inside one long router request (Stop and per-call ledgering are simpler with the app driving three small endpoints).
- 2026-09-29, after the first live image call: `openai/gpt-5-image-mini` cost $0.0417 for one image, more than the 3¢ cap. `refine.estimate_micro.image_generate` is 42,000, and `/skin/plan` never returns a path the cap cannot afford once: it takes Jev's next most likely affordable path and returns a `note` that the run shows.
- 2026-09-29: the library's "Open terminal" opens a new box with a built theme and a library material as the stage skin (`shared/src/skins/terminals.ts`, Canon C-060).
