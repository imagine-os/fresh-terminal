# 0014 — realtime voice behind a provider seam

- Seam: `app/src/voice/types.ts` — `VoiceProvider { start, stop, setMuted }` and `VoiceEvents { onTranscriptDelta(text, isFinal), onAssistantText, onAssistantAudio, onLevel, onState, onError }`. `useVoice` owns one provider at a time; the composer only sees `{ state, level, interim, toggle, muted }`.
- **WebSpeechVoice** (default, no key): browser `SpeechRecognition`, continuous with interim results; restarts after the browser's silence timeout; a Web Audio level meter drives the waveform. Interim text renders gray in the composer; finals append to the composer text and become chips through the local tagger. Nothing is sent anywhere.
- **OpenAIRealtimeVoice** (complete): `POST <router>/realtime/session?provider=openai` → the router calls `POST https://api.openai.com/v1/realtime/client_secrets` with `session.type = realtime`, `session.model = gpt-realtime-2.1`, `session.audio.input.transcription.model = gpt-live-transcribe` and returns `{ value, model, transcribe_model, sdp_url }`. The browser: `RTCPeerConnection`, mic track, data channel `oai-events`, `POST https://api.openai.com/v1/realtime/calls` (application/sdp) with the ephemeral key, remote track → `<audio autoplay>` with a mute toggle. Events (verified 2026-09-29): `conversation.item.input_audio_transcription.delta/.completed` → live transcript; `response.output_audio_transcript.delta/.done` and `response.output_text.delta/.done` → assistant text. Final user transcripts become user lines; assistant finals become assistant lines.
- **GeminiLiveVoice** (skeleton, labelled not wired): `POST <router>/realtime/session?provider=gemini` → the router creates a single-use ephemeral token (`POST https://generativelanguage.googleapis.com/v1beta/auth_tokens`, `liveConnectConstraints.model = models/gemini-3.8-live`, input/output transcription on) and returns `{ token, model, ws_url }`; the client opens `BidiGenerateContentConstrained?access_token=…`, sends `setup`, and maps `serverContent.inputTranscription / outputTranscription / modelTurn.parts.inlineData`. Missing: 16 kHz PCM capture and 24 kHz playback (pass 4).
- Ledger: one `charge` per realtime session, `what: 'voice.session.estimate'`, `unit_kind: 'second'`, `units` = seconds, `model` = realtime model, `price = cost` = seconds/60 × (audio in + audio out per minute) from `router/prices.json` `realtime` rows, which are estimates until real usage is wired. `second` was added to `UNIT_KINDS` (shared + module).
- UI: mic button is toggle or press-to-talk (setting `voiceMode`), a five-bar waveform driven by the level, gray interim text in the composer mirror, provider picker in Settings (K) with "not configured" when `GET /realtime/providers` says the router lacks the key, `V` toggles voice. Spanish strings filled.
- Not verified live: no OpenAI or Google key was available in the build environment, so the realtime providers are tested through their pure event mappers and the router's fake-fetch tests, not end to end.
