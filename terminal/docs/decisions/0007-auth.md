# 0007 — auth: Clerk, behind a seam, not wired in pass 1

- Chosen: Clerk. Reasons: hosted UI, OIDC-compliant tokens that SpacetimeDB accepts as identity tokens, small client SDK.
- Pass 1 ships the seam only: `app/src/auth/types.ts` (`AuthProvider`: `getIdentityToken`, `currentUser`, `signIn`, `signOut`), `AnonymousAuth` (stable per-browser id in localStorage) in use, `ClerkAuth` stub that throws `NotWiredError`.
- The "save / sign in" affordance is a not-wired placeholder with tooltip and toast.
- Anonymous boxes stay reachable after sign-in by keeping the anonymous id and linking it to the signed-in identity (pass-2 task `clerk-wiring`).
